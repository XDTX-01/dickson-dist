# dickson-dist
## 仓库定位
前端构建产物**专属中转仓库（中转站）**，作为 A 源码仓库 和 C 发布仓库之间的中间接力层。
✅ 本仓库**不存放业务源代码、不接收人工代码提交**，所有文件、提交记录全部由 A 仓库的 GitHub Actions 流水线自动生成、自动推送。
✅ 核心作用：统一托管打包后的 dist 静态资源，作为稳定的触发源，驱动下游 C 仓库执行最终打包、构建、发布流程。

## 完整链路
> A（源码仓库）→ 手动触发流水线 → 执行 npm 打包生成 dist → 同步 dist 产物到本仓库 B → 发送 repository_dispatch 事件 → C（发布仓库）接收事件，开始打包发布
1. A：源码仓库，存放 Vue/前端源码，开发者在这里改代码、提交；在 Actions 页面手动触发构建流程
2. B：本仓库 dickson-dist，中转站，只存打包好的 dist 产物，是上下游的桥梁
3. C：发布仓库，接收 B 推送的事件，拉取 dist 资源，执行最终打包、产出可分发包、版本归档
